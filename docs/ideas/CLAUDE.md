# Ideas Directory

This folder contains product idea documents and design specs. These are **read-only reference material**, not an active codebase and not approved work.

Do not modify these files unless explicitly asked. They inform GuideRail's design; some predate the monorepo and use the project's earlier names (Viewscape, viewscape-core).

Implementation plans derived from these documents live in `docs/plans/`. Working instructions for the repository are in the root `AGENTS.md`.
